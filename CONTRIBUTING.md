# Contributing

Use TypeScript for application code and scripts. Keep the four-card listening screen free of extra controls; settings belong behind the central long press.

Run `npm ci`, `npm test`, and `npm run build`. Check settings in a real browser, and verify native file import when changing storage or picker behavior. Test Android and an iPad simulator for native changes. Distinguish simulator checks from physical-device checks.

Do not commit personal recordings, imported files, signing keys, provisioning profiles, device identifiers, or credentials. Keep provider playback inside official visible players.

Describe the changed behavior and the checks performed in your pull request. New contributions are licensed under MIT.
